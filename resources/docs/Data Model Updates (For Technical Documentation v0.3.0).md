## Implementation Notes

### Authentication Middleware Changes

1. **Check temporary roles:** When validating permissions, merge `role` with `temporaryRoles` (filtering expired ones)
2. **Username uniqueness:** Check both `users` and `users_pending` collections
3. **Role limit enforcement:** Query count before allowing registration/elevation
4. **Bootstrap detection:** Check if `users` collection is empty for first registration

### Agent Configuration Update

```toml
# /etc/hydra/agent.toml
```

### Security Considerations

1. **Password transmission:** Agent passes credentials over TLS only
2. **Credential storage:** Agent config stores only the API key, not user password
3. **API key scope:** Node API keys are scoped to that node only
4. **Audit trail:** All node registrations track the registering user
